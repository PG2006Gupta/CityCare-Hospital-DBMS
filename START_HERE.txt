STEP 1 — RUN THE APP
--------------------
    cd fullstack
    python3 server.py

Open http://localhost:8000 in your browser.
(Windows: use "python" instead of "python3".)
No installation, no npm, no internet, no API keys needed.

IF SOMETHING BREAKS
---------------------------------------------------------------------
  - Broken SQL Console data? Click "Reset DB" on that page.
  - Port busy?  PORT=8080 python3 server.py
  - Blank page? Open http://localhost:8000/ (not the .html file directly).
  - Still stuck? Delete database/hospital.db and restart the server.
