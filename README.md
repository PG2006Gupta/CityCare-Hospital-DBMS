# 🏥 City Care Hospital – Hospital Management System

**A Full-Stack DBMS Project | Hospital & Clinic Management System**

[🌐 Live Project](https://pg2006gupta.github.io/CityCare-Hospital-DBMS/)

## 📌 About the Project

**City Care Hospital** is a full-stack Hospital Management System developed as part of the **Database Management Systems (DBMS)** subject project.

The project aims to digitize and simplify hospital operations by providing a centralized platform for managing patients, doctors, appointments, hospital rooms, billing, and pharmacy records.

It integrates a structured relational database with an interactive web interface to demonstrate how database management concepts can be implemented in a real-world application.

The system focuses on efficient data organization, relational database design, SQL operations, data integrity, and simplified hospital administration.

## 🎯 Project Objectives

- Develop a centralized hospital management platform.
- Maintain organized patient and doctor records.
- Simplify appointment scheduling and management.
- Manage hospital beds and room availability.
- Handle billing and pharmacy-related records.
- Implement relational database concepts using SQL.
- Demonstrate database relationships, constraints, views, and triggers.
- Provide an interactive interface for accessing hospital information.
